
### Overview
This repository contains the official code for CycleTrack / CycleTrack-EM, as presented in the paper: [Variational Inference for Cyclic Learning (ICLR 2026)](https://openreview.net/forum?id=c1jWNZ1Zqg).

Like CycleGN, this repository is intended to validate the variational framework, so the hyperparameters have not been carefully tuned for optimal benchmark performance. Readers are encouraged to train and fine-tune the model themselves to achieve the best results
This project provides 4 models that share the same network architecture, which we refer to as **CycleTrack**. A detailed description of the architecture can be found in the paper. These four models are trained with different settings, evaluating the tracking performance of CycleTrack using **single-step** and **Expectation-Maximization**-based cyclic algorithms under **unsupervised settings** (with detector-provided boxes) and **strictly unsupervised settings** (with unsupervised optical flow-provided boxes).
  
We provide checkpoints for all 4 models ([GoogleDrive](https://drive.google.com/drive/folders/1gBFCh4bqyF8Ek7PuP01Ze8vSnBp5XPk4?usp=drive_link)). If you wish to test them, please maintain the folder structure and place them under the root directory of this project as: `${CycleTrack_ROOT}/checkpoints/...`.

### Clone repositories:
```
git clone https://github.com/ZTak3n/CycleTrack
cd CycleTrack
```

### Prepare the dataset:
Put the tracking datasets in `./data`.

Download the following files and place them in the same folder:

- The detection bounding box files generated by [DETA](https://github.com/jozhang97/DETA) ([Google Drive](https://drive.google.com/file/d/1z9RWlsfLXEtd_0-8uyZVW5xv04i6ep9Q/view?usp=drive_link))

- The optical flow bounding box files filtered from [USOT](https://github.com/VISION-SJTU/USOT), which were generated using [ARFlow](https://github.com/lliuz/ARFlow) ([Google Drive](https://drive.google.com/file/d/1yd7wmu6dJEDwYN0F221dKDbViubk5fU-/view?usp=drive_link))

The directory structure should look like:
```
${CycleTrack_ROOT}
 -- data

         |-- airplane
         |-- basketball
         ...
     -- got10k
         |-- test
         |-- train
         |-- val

         |-- annotations

         |-- TRAIN_0
         ...
         |-- TRAIN_11

     -- vid
         |-- train
            |-- ILSVRC2015_VID_train_0000
            |-- ILSVRC2015_VID_train_0001
            ...

```

### Prepare the environment:
Install and activate the environment:
```
conda create -n cycletrack python=3.8
conda activate cycletrack
bash install.sh
```

Run the following command to set paths for this project
```
python tracking/create_default_local_file.py --workspace_dir . --data_dir ./data --save_dir .
```

### Train:
Download the unsupervised ViT backbone from DropVAE ([GoogleDrive](https://drive.google.com/file/d/1qMuBJtNIQQ-NCz98Pig72YVKQdasc49h/view?usp=share_link)) as `${CycleTrack_ROOT}/k700_800E_checkpoint_final.pth`.
Training with multiple GPUs
```
python -m torch.distributed.launch --nproc_per_node 8 lib/train/run_training.py --script cycletrack --config detection_EM --save_dir . 
```
You can choose a config from `detection_singleStep`, `flow_singleStep`, `detection_EM`, or `flow_EM` for training.

### Test and evaluate:  
- LaSOT
```
python tracking/test.py cycletrack detection_EM --dataset lasot --threads 8
python tracking/analysis_results.py   --dataset_name lasot --model_name cycletrack --parameter_name detection_EM
```
- TrackingNet
```
python tracking/test.py cycletrack detection_EM --dataset trackingnet --threads 8
python lib/test/utils/transform_trackingnet.py --tracker_name cycletrack --cfg_name detection_EM
```

You can choose a config from `detection_singleStep`, `flow_singleStep`, `detection_EM`, or `flow_EM` for testing.
